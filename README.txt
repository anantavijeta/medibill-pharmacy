MediBill image assets
=====================

Upload these image files into the `assets` folder in your GitHub repository.

Suggested code references:
- medicine_capsules.png: generic medicine/capsule category
- pill_illustration.jpg: decorative medicine illustration
- ors_packet.png: ORS product image
- digital_thermometer.png: thermometer product
- first_aid_bandage.png: first-aid supplies
- pharmacy_interior.png: pharmacy section/banner
- vitamin_c.png: vitamin C product example
- pulse_oximeter.png: pulse oximeter product
- antacid_gaviscon.png: antacid product example
- petroleum_jelly.png: personal care product example
- medicine_blister_packs.png: generic medicine category image

Note: Only use a product image for the exact product shown. If your catalogue names a different brand or package, use a generic category image instead of implying it is the exact product.
